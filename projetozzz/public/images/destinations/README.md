# Destinos para LoginBackground

Esta pasta contém as imagens de destinos turísticos para o componente LoginBackground.

## Imagens necessárias:

Para melhor performance e experiência, adicione as seguintes imagens JPG em alta qualidade (recomendado: 1920x1080px):

- `paris.jpg` - Torre Eiffel / Paisagem de Paris
- `tokyo.jpg` - Panorâmica de Tóquio / Shibuya
- `bali.jpg` - Praia tropical de Bali
- `newyork.jpg` - Skyline de New York
- `dubai.jpg` - Dubai / Deserto de luxo
- `barcelona.jpg` - Sagrada Familia / Barcelona
- `amsterdam.jpg` - Canais de Amsterdam
- `santorini.jpg` - Casarões brancos de Santorini
- `bangkok.jpg` - Templos / Bangkok à noite
- `sydney.jpg` - Opera House / Sydney

## Como adicionar:

1. Baixe as imagens de alta qualidade (recomendado Unsplash, Pexels ou Pixabay)
2. Redimensione para 1920x1080px se necessário
3. Salve como JPG nesta pasta com os nomes listados acima

## Fallback:

Se uma imagem local não for encontrada, o sistema carregará automaticamente a imagem da Unsplash como fallback.

## Recomendações:

- Use imagens em paisagem (16:9)
- Tamanho máximo: 500KB por imagem
- Formato: JPG para melhor compressão
- Qualidade: Alta definição para melhor visual
