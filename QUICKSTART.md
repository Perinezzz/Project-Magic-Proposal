## 🆘 Problemas?

### PDF não gera?
1. Abrir DevTools (F12)
2. Ver console para erros
3. Tentar qualidade \"Draft\"

### WhatsApp não abre?
1. Verificar número (com código país: 55)
2. Testar em navegador privado
3. Usar fallback Web WhatsApp

### Imagens não aparecem?
1. Verificar URLs (deve ser HTTPS)
2. Verificar CORS
3. Usar qualidade \"High\"
